# Lab MST - Spotify 2023 Data Analysis using Power BI

## Objective
To analyze the Spotify 2023 dataset using Microsoft Power BI and identify meaningful patterns in music characteristics, platform presence, playlist exposure, chart performance, outliers, and artist concentration.

## Tool Used
Microsoft Power BI

## Dataset
Spotify 2023 Dataset

## Analysis Performed
1. Music Analysis
2. Cross-Platform Presence
3. Playlist Exposure and Streaming Performance
4. Chart Position and Song Performance
5. Outlier and Exceptional Song Analysis
6. Artist Concentration and 80/20 Analysis

## Report
Power BI report created using the Spotify 2023 dataset.
